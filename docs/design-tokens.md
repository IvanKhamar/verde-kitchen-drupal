# Design tokens

Design tokens are the named values the Verde theme is built from: colours, type,
spacing, radii, shadows and breakpoints. In this project they replace a Figma file:
every visual decision is written down here and in one source file.

- **Source:** `web/themes/custom/verde/src/scss/abstracts/_tokens.scss` (Sass maps)
- **Output:** CSS custom properties on `:root`, generated by
  `src/scss/base/_custom-properties.scss`, for example `--color-primary`.

Components use the custom properties (`color: var(--color-primary)`), so a value
changes in one place. Breakpoints are the exception: CSS custom properties do not
work inside `@media`, so they stay Sass variables and are used through the
`mq()` mixin.

### Contrast (WCAG 2.1 AA)

AA needs **4.5:1** for normal text and **3:1** for large text and UI parts such as
form field borders and focus indicators. Ratios were calculated with the WCAG
relative luminance formula.

| Foreground / background                   | Ratio   | Passes     |
| ----------------------------------------- | ------- | ---------- |
| text / bg                                 | 14.69:1 | AA, AAA    |
| text-muted / bg                           | 6.74:1  | AA         |
| text-muted / surface-alt                  | 6.25:1  | AA         |
| primary / bg (links)                      | 6.28:1  | AA         |
| white / primary (button)                  | 6.39:1  | AA         |
| white / primary-dark (button hover)       | 10.15:1 | AA, AAA    |
| primary-dark / primary-light (badge)      | 7.63:1  | AA, AAA    |
| accent-dark / accent-light (badge)        | 6.52:1  | AA         |
| text-inverse / footer-bg                  | 11.73:1 | AA, AAA    |
| danger / bg                               | 6.43:1  | AA         |
| focus / bg (focus ring)                   | 9.98:1  | 3:1 for UI |
| border-strong / white (form field border) | 3.64:1  | 3:1 for UI |

`--color-accent` (`#e76f51`) has only about 3.1:1 against white, so it is never used for text.

## Typography

System font stacks: the browser uses fonts already installed on the device, so there
are no font files to download, no render-blocking requests and no layout shift when a
web font arrives.

| Token                   | Value                                                |
| ----------------------- | ---------------------------------------------------- |
| `--font-family-body`    | `system-ui, -apple-system, 'Segoe UI', Roboto, …`    |
| `--font-family-heading` | `ui-rounded, 'SF Pro Rounded', system-ui, …`         |
| `--font-family-mono`    | `ui-monospace, 'Cascadia Code', Consolas, monospace` |

Font sizes are **fluid**: `clamp(min, preferred, max)` grows the size with the
viewport between about 360px and 1280px, so headings need no breakpoints.

| Token              | Min (360px) | Max (1280px) | Used for        |
| ------------------ | ----------- | ------------ | --------------- |
| `--font-size-sm`   | 14px        | 14px         | Meta, badges    |
| `--font-size-base` | 16px        | 16px         | Body text       |
| `--font-size-md`   | 18px        | 20px         | Lead text       |
| `--font-size-lg`   | 20px        | 24px         | h4, card titles |
| `--font-size-xl`   | 24px        | 32px         | h3              |
| `--font-size-2xl`  | 30px        | 44px         | h2              |
| `--font-size-3xl`  | 36px        | 60px         | h1              |

Weights: `--font-weight-regular` 400, `--font-weight-semibold` 600, `--font-weight-bold` 700.
Line heights: `--line-height-tight` 1.2 (headings), `--line-height-base` 1.6 (text).

## Breakpoints

Mobile first: styles without a media query apply to the smallest screens, and
`@include mq('md') { … }` adds styles from that width up.

| Name | Min width | Typical device      |
| ---- | --------- | ------------------- |
| —    | 0         | Phones (from 360px) |
| `sm` | 480px     | Large phones        |
| `md` | 768px     | Tablets             |
| `lg` | 1024px    | Small laptops       |
| `xl` | 1280px    | Desktops            |

Content width is limited by `--container-max-width` (1200px), with a side padding of
`--space-4` on phones and `--space-6` from `md` up.
