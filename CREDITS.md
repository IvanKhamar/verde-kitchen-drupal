# Credits

## Brand

Verde Kitchen is a fictional brand invented for this portfolio project. Any similarity
to a real company, product or logo is unintended.

## Images

All demo images in `scripts/demo-content/images/` are original illustrations made for
this project. `scripts/demo-content/build-images.sh` generates them from SVG code and
renders them to PNG, so no third-party images are used.

If photos are added later, only CC0 (public domain) images will be used. Each one will be
listed here with its source URL.

## Texts

Product descriptions, recipes and news texts are written for this project.
